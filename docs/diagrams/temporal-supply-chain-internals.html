What crosses the Temporal boundary, and what doesn'tTemporal 경계를 넘는 것과 넘지 않는 것

The workflow only orchestrates — it can't call an LLM directly, because everything it passes to an activity is serialized to JSON. specialist_activity works around that by rebuilding its LLM from a plain string (agent_name) instead of receiving one, and caching the result so retries don't pay for it twice. 워크플로우는 오케스트레이션만 담당하며 LLM을 직접 호출하지 않습니다 — 액티비티에 넘기는 모든 값이 JSON으로 직렬화되기 때문입니다. specialist_activity는 LLM 객체를 직접 받는 대신 문자열(agent_name)만으로 LLM을 다시 만들고, 그 결과를 캐싱해 재시도할 때 비용을 두 번 치르지 않게 합니다.
